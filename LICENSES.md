# Licences: dependencies, data and assets

Checked by `python scripts/licence_scan.py` (CI job `licence-scan`) against `config/licence_allowlist.txt`.
Allowed: MIT, Apache-2.0, BSD-2/3-Clause, ISC, PSF, CC BY 4.0, CC0 and their permissive variants (MIT-0, MIT-CMU,
0BSD, Zlib, BSL-1.0, CNRI-Python), plus named paid-commercial outputs. GPL, AGPL, LGPL and non-commercial
licences always fail the job. Last run: 21 Oct 2026, 202 entries, 0 offenders.

WHYLINE's own code is MIT (`pyproject.toml`).

**Named exceptions:**

| Package | Licence | Why it is allowed |
|---|---|---|
| `certifi` (Python) | MPL-2.0 | CA certificate bundle pulled in by `httpx`/`requests`, used unmodified. MPL-2.0 is file-level copyleft and puts no obligation on our code. |
| `tqdm` (Python) | MPL-2.0 AND MIT | Progress bars pulled in by ML dependencies, used unmodified; same reasoning. |
| `webgl-constants` (npm, via three/drei) | MIT | Its `package.json` has no licence field; the bundled `LICENSE` file is MIT (checked 21 Oct 2026). |

**Excluded on purpose** (`config/pins.txt`): ultralytics / YOLOv8 weights (AGPL-3.0), sn-gamestate (GPL-3.0),
BroadTrack (non-commercial), gfootball (never used).
