# Fonts in the video (v8 on)

Every on-screen word of the PITCHSIGHT video (overlays, cards, captions) is set in **DejaVu Sans** (Bold and Book),
read from the copy matplotlib ships (`matplotlib/mpl-data/fonts/ttf/DejaVuSans*.ttf`); no font file is committed.
